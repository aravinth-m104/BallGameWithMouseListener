# BallGameWithMouseListener
BallGame is an interactive Java application that demonstrates mouse event handling with a unique twist - ball on the screen axtively avoid your cursor. When you move your mouse towards a ball, it will move away in opposite direction, creating an interestinng chase/avoidance dynamic.

**Features**
•	Ball detect mouse cursor proximity.
•	Automatically movement away from the cursor.
•	Smooth physical-based movement.
•	Visual feedback showing ball movement.
•	Customizable ball count, size, and colors.  


Requirements:
•	Java Development Kit (JDK) 8 or later
•	Java AWT and Swing Libraries.

Code Structure:
•	BallGame.java – Main class containing the game window and mouse listener and ball object avoidance behavior.
